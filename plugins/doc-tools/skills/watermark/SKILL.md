# watermark:证件外发前自动加水印(不看图)

证件、执照、合同这类文件发给第三方前,先用 `scripts/watermark.py` 加一层斜向铺满全页的半透明文字水印,写明用途和日期,再把**加了水印的新文件**发出去。原件不动。

```bash
export WM_DATA="${CLAUDE_PLUGIN_DATA}"
WM="${CLAUDE_PLUGIN_ROOT}/skills/watermark/scripts/wm.sh"
```

## 硬规矩:不看图

这类文件里是身份证号、人脸、银行卡号,不该进对话记录,所以:

- **不用 Read 打开图片或 PDF,不截图,不 OCR,不 `pdftotext`,不把内容转成 base64 打印。** 加水印前后都不看,结果靠脚本的自检输出判断。
- **判断哪些文件要加水印,只看文件名、所在目录和当前任务**。光看名字分不出是什么文件时,问用户,别打开看。
- 只需要知道页数、尺寸时,用 `pdfinfo`(只看 `Pages` / `Page size` 行)或 `sips -g pixelWidth -g pixelHeight`,不读内容。

## 什么时候自动加

正在做的事里有「把文件交给外部」这一步(上传表单、发邮件附件、发到群里、交给园区 / 银行 / 代办),而文件属于下面这些,就**先加水印再发**,不用等用户提:

身份证 / 护照 / 港澳通行证 / 户口本 / 驾驶证;营业执照 / 开户许可证 / 各类资质证书;银行卡 / 存折 / 流水;社保、个税、纳税记录;合同、协议、证明信、授权书;其他带个人信息或公司公章的扫描件和照片。

**这几种情况先问,别直接加:**

- **带电子签章的 PDF**(电子营业执照、一网通办盖章件、合同电子签):加水印会让签名验证失效。对方要验签就发原件。拿不准用 `pdfsig 文件.pdf` 看有没有签名(只看输出里有没有 `Signature #`,不看别的)。
- 对方明确要求「原件 / 无水印」(部分银行、政府系统上传时会拒收带水印的件)。
- 公司对外公开的宣传材料、官网图片:不是证件,不用加。

## 步骤

1. **定水印文字**。格式:`仅用于<接收方><事由> 他用无效`,例如 `仅用于XX园区入驻申请 他用无效`、`仅用于招商银行企业开户 他用无效`。从当前任务里推断接收方和事由;推不出来就问用户一句,不要写成空泛的「仅供使用」。日期默认自动加在第二行(今天)。
2. **跑脚本**(输出默认和原件放在同一目录,文件名加 `-水印` 后缀;身份信息文件**不要输出到 git 仓库里**):

   ```bash
   # 逐个加,图片还是图片,PDF 还是 PDF
   sh "$WM" 身份证正面.jpg 营业执照.pdf -t "仅用于XX申请 他用无效"

   # 身份证正反面拼到一页 A4 再加水印(常见要求)
   sh "$WM" 人像面.jpg 国徽面.jpg --combine ~/Downloads/身份证正反面-水印.pdf -t "仅用于XX申请 他用无效"

   # 图片也要出 PDF
   sh "$WM" 社保记录.jpg --pdf -t "仅用于XX申请 他用无效"
   ```

3. **看自检输出**,每个文件一行:
   - `OK   原件 -> 输出 | 页数 | 尺寸 | 水印改动像素 x%` —— 成功。一般在 5%~15%。
   - `FAIL ...` —— 水印几乎没上去,输出已自动删掉、退出码 2。调大 `--opacity` 或 `--scale` 重跑。
   - 只要有一行不是 OK,就不发。
4. **发的是 `-水印` 那个新文件**,并告诉用户输出路径和用的水印文字。用户想自己看效果,让他自己打开,你不打开。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `-t / --text` | 必填 | 水印正文 |
| `--date` | `today` | 第二行:`today` / `none` / 任意文字 |
| `-o / --outdir` | 原件所在目录 | 输出目录 |
| `--combine OUT.pdf` | — | 所有输入拼到 A4 上出一个 PDF |
| `--per-page` | 2 | `--combine` 每页放几张(上下排) |
| `--pdf` | — | 图片也输出 PDF |
| `--keep-vector` | — | PDF 不转成图片,直接叠矢量水印;原文字可选可搜,但**水印能被 PDF 编辑软件删掉**。证件类别用,长文档 / 合同对方要能搜索时才用 |
| `--dpi` | 200 | PDF 转图和拼 A4 的分辨率 |
| `--opacity` | 0.35 | 不透明度 |
| `--color` | `110,110,110` | R,G,B |
| `--angle` | 30 | 倾斜角度 |
| `--scale` | 0.035 | 字号 = 短边 × scale |
| `--font` | 自动找系统中文字体 | 字体文件路径 |

## 行为细节

- **PDF 默认整页转成图片再加水印**(`pdftoppm`),水印和内容合在一起抠不掉;代价是文字不能再选中。
- 手机照片按 EXIF 方向自动转正;**输出不带 EXIF**,顺带去掉 GPS 位置和机型。
- HEIC 用 macOS 自带 `sips` 先转 JPEG;BMP / TIFF / HEIC 输出成 JPEG。
- 不覆盖已有文件,重名时自动加 `-2`、`-3`。
- 加密 PDF 会直接报错退出,请用户先解密。

## 依赖

- Python 3.9+。**Pillow 不用自己装**:`wm.sh` 先看系统 `python3` 有没有;没有(包括 Homebrew / uv 的 Python 不让 `pip3 install` 的情况),第一次用时自动在插件数据目录建虚拟环境装上,终端会打一行「首次使用…」,以后直接复用。`--keep-vector` 要的 pypdf、reportlab 同样自动补装。
- 自动安装失败(没网 / PyPI 连不上)时,脚本会打出手动安装的命令,照着跑一次即可。
- PDF 输入:poppler(`brew install poppler`,提供 `pdftoppm`),这个要自己装。
- 一律用 `sh "$WM"` 调用,不要直接 `python3 watermark.py`——直接调就绕过了上面的自动装依赖。
- 中文字体:macOS 自带;Linux 装 `fonts-noto-cjk`
